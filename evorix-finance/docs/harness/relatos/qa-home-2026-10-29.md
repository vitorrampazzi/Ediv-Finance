# QA — homepage e multiagentes — 29/10/2026

## Escopo e aceitação

QA delegado pelo Orquestrador nesta rodada autorizada pelo usuário. Harness v2
aceita o papel `qa`, reserva seus caminhos e serializa as atualizações do quadro.
Aceitação: título exatamente Escola do Dividendo no HTML e após hidratação,
navegação e reload; progressão Empresa → Pesquisa → Dividendos e retorno;
animação das três cenas, figuras legíveis em telas baixas/mobile, movimento
reduzido estático, ausência de overflow e erros inesperados no navegador.

## Verificações reais

- Node local inicial 24.22.1: `npm test`, 128/128; `npm run lint` e build aprovados.
- Validação final com Node 22.21.0, compatível com a família configurada na
  produção: todos os 128 testes de `npm test` aprovados, ESLint aprovado e
  `scripts/build.mjs` aprovado, incluindo TypeScript, bundle e oito HTMLs públicos.
  Os executáveis foram chamados diretamente com o Node22 para que os subprocessos
  também herdassem essa versão; npm local serviu apenas para instalação/ferramentas.
- Browser Node22/Chrome: 7/7 verificações aprovadas, incluindo HTML pré-renderizado
  e seis cenários: 1440×1000, 1366×650, 390×844, 320×760, movimento reduzido
  desktop e mobile.
- Em todos os cenários: passos 0→1→2→1→0; texto e ilustração correspondentes;
  animações CSS ativadas nas três cenas, `animationName=none` quando reduzido;
  nenhum movimento em execução no modo reduzido; navegação metodologia→home,
  reload, título correto e nenhuma requisição API inesperada.
- Desktop testa cruzamento do ponto de seleção com deslocamentos de apenas 8px
  para cada lado, cobrindo a falha de seleção baseada apenas em thresholds de IO.
- Console/pageerror: zero erros inesperados. O HTTP401 de `/api/auth/me` é a
  resposta simulada e esperada para visitante; contabilizado separadamente.
- Sem overflow horizontal superior a 2px. Capturas desktop, mobile320 e desktop
  baixo inspecionadas visualmente; texto e figuras permanecem legíveis.
- `git diff --check` aprovado. Arquivos QA não contêm credenciais.
